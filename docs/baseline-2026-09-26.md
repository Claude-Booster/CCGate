## Why no dollar figures

`miss_audit`'s cost path is broken; every dollar figure it produced is discarded until
fixed (§12.9 — an impossible value should stop the report):

1. **Negative total cost** (`miss_audit.py:102`) — the fresh-input term is
   `(input_tokens − cache_read − cache_creation) × rate_in`, but `input_tokens` is
   already fresh-only, not a grand total. With cache_read ≫ input_tokens the term goes
   hugely negative. Should be `input_tokens × rate_in`.
2. **`turns_remaining_est` ≈ 66,661** (`miss_audit.py:54`) — uses `input_tokens` as
   per-turn total (~3/turn for cached turns). This is BUILD-SPEC §12 Q1, underspecified:
   it never said which token count. Every dollar figure multiplies through it.
3. **Subagent inflation** — 92.6% of the corpus is subagent cold-starts counted as
   misses.
4. **Attribution mislabelled** — the `D1.unclassified` "fix: upgrade Claude Code"
   (`taxonomy.py:39`) is wrong; attribution needs the blocked statusline payload, not a
   newer version (CLI 2.1.278 already exceeds the floor).

Cost baseline is deferred until 1, 2, and 3 are fixed and Q1 is resolved.
